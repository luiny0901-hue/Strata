# Claude Code CUA 입력 정책

Claude의 CUA 연결은 이 저장소의 `mcp.mjs`와 창 범위 Rego 정책을 사용합니다. 일반 관찰·입력 도구는 정확한 창 식별과 최신 화면 근거를 요구하고 백그라운드 입력만 허용합니다. 사용자 마우스·키보드, 전역 입력, 셸/네이티브 입력 우회는 사용하지 않습니다.

전경 입력이 꼭 필요한 동작은 `approved_foreground_action`을 통해 실제 승인 요청을 거쳐야 합니다. 승인 대기 중에는 다른 동작을 겹쳐 보내지 않습니다. 승인·화면 식별·결과가 불분명하거나 CUA가 지원하지 않는 동작이면 중단하고 상태를 보고합니다. UAC와 보안 데스크톱은 자동으로 조작하지 않습니다.

프록시는 창 식별, 화면 근거, 좌표 검증, 입력 중복 방지와 요청 기한을 관리합니다. 시간 초과는 동작이 실행되지 않았다는 뜻이 아니므로 결과를 확인하기 전에 같은 입력을 다시 보내지 않습니다.

읽기 전용 설치 확인은 `python tools/cua-driver/verify_background_policy.py`를 사용합니다. `--coordinates`는 화면을 읽을 수 있는 창이 있을 때만 추가 조회를 수행하며 클릭하지 않습니다.
