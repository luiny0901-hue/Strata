# Claude Code CUA 입력 정책

Claude의 CUA 연결은 이 저장소의 `mcp.mjs`와 창 범위 Rego 정책을 사용합니다. 일반 관찰·입력 도구는 정확한 창 식별과 최신 화면 근거를 요구하고 백그라운드 입력만 허용합니다. 일반 입력에서 사용자 마우스·키보드와 전역 입력을 사용하지 않으며 셸/네이티브 입력으로 우회하지 않습니다.

백그라운드 미지원 또는 최신 상태로 미실행이 확인된 동작은 `approved_foreground_action`으로 실제 사람 승인을 받은 뒤 CUA 전경 입력을 사용합니다. 전송 성공은 완료 증거가 아니며 결과가 불명확하면 상태부터 확인합니다. 승인 후에도 가능한 동작은 백그라운드를 유지합니다. 승인 거부·만료·승인 기능 부재이면 해당 GUI 단계와 의존 작업만 보류합니다. 승인 대기 중에는 다른 동작을 겹쳐 보내지 않습니다. 승인·화면 식별·결과가 불분명하거나 CUA가 지원하지 않는 동작이면 중단하고 상태를 보고합니다. UAC와 보안 데스크톱은 자동으로 조작하지 않습니다.

프록시는 창 식별, 화면 근거, 좌표 검증, 입력 중복 방지와 요청 기한을 관리합니다. 시간 초과는 동작이 실행되지 않았다는 뜻이 아니므로 결과를 확인하기 전에 같은 입력을 다시 보내지 않습니다.

읽기 전용 설치 확인은 `python tools/cua-driver/verify_background_policy.py`를 사용합니다. `--coordinates`는 화면을 읽을 수 있는 창이 있을 때만 추가 조회를 수행하며 클릭하지 않습니다.
