# 출력 복구 처리 비용 (2026-10-21)

도구 인자 조각마다 structuredClone으로 전체 응답 객체를 복사하던 경로를 필요한 객체만 복사하도록 바꿨다. 완료 신호 전 도구 실행 차단과 인자 JSON 검사는 유지한다.

CPU 합성 SSE 시험: 4096바이트 청크, 6000개 이벤트, 워밍업 1회 제외 7회 중앙값. 같은 PC에서 baseline과 수정본을 순차 실행했다.

| 입력 | 기존 | 수정 |
|---|---:|---:|
| 텍스트 | 21.67ms | 22.28ms |
| 도구 인자 | 68.52ms | 40.78ms |

두 입력 모두 출력 SHA256이 수정 전후 동일했다. 텍스트 경로에 개선 근거는 없으며 도구 경로의 처리 시간은 약 40.5% 감소했다. 전체 작업 완료 시간이나 모델 prefill/decode 속도를 측정한 결과가 아니다. 통신 지연, 모델 생성, 파일 IO, 빌드가 실제 작업에서 더 큰 비중을 가질 수 있다.

재현: `node tools/benchmark_opencode_stream.mjs [비교할 모듈 경로]`. 원본 스냅샷은 diagnostics/stream-bottleneck-20261021/baseline.mjs에 보존했다. 도구 호출을 실제 실행하거나 GPU/서버를 시작하지 않는다.
