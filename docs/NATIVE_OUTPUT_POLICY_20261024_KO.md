# 엔진과 무관한 비웹 산출물 정책 — 2026-10-24

## 발견과 보완

기존 지침은 브라우저 데모 대체를 막았지만 Electron/Tauri를 데스크톱으로 분류하고 성능 근거가 있으면 선택할 수 있는 예외가 있었다. 사용자의 비웹 요구에 맞춰 이 예외를 제거했다.

- 웹을 명시하지 않은 새 프로그램·게임은 네이티브 제품으로 구현한다.
- Unity/Unreal을 쓰지 않거나 다른 엔진·자체 엔진·엔진 없이 개발해도 웹으로 전환하지 않는다.
- 사용자 지정 엔진 미사용 요구를 우선하고 네이티브 라이브러리 사용을 허용한다. 특정 엔진을 강제하지 않는다.
- Electron/Tauri/WebView로 웹 주 UI를 감싼 실행 파일도 비웹 요구의 대체안이 아니다. .exe 확장자와 설치 가능 여부만으로 네이티브 제품이라고 판단하지 않는다.
- 세련된 웹 같은 디자인, 온라인 기능, 서버/API 연동은 웹 제품 허가가 아니다. 필요한 보조 웹 서비스는 주 제품과 구분한다.
- 사용자가 명시적으로 웹 제품을 요청하면 그 요청을 따른다. 기존 웹 프로젝트를 일괄 변환하거나 정상 코드를 삭제하지 않는다.

전역 한국어 지침과 desktop 프로젝트 템플릿의 충돌 문구를 정리했다. 압축은 산출물 요구를 유지하고 웹 전환을 허가하지 않는 기존 복구 규칙을 그대로 재사용한다. 바이너리 분석을 위한 REA의 Electron 분석 지원은 웹 제품 생성 기본값과 관계없으므로 유지했다.

## 검증과 한계

관련 지침/설치/portable-profile 회귀 검사 28개 통과. 실제 생성 설치 파일에도 새 비웹 규칙이 들어가는 것을 검사한다. 전역 OpenCode JSON과 모델/GPU/압축 설정은 변경하지 않는다.

실제 모델의 5가지 기술 선택 응답도 확인하려 했으나 127.0.0.1:8080의 /v1/models가 연결 거부(WinError10061)여서 추론을 보내지 못했다. 이 시도의 모델 동작 검증은 NOT_RUN이며, 서버를 자동 시작하거나 재시작하지 않았다. 지침 검사가 모든 모델/컨텍스트에서 무오류 선택을 보장하지 않는다.

증거 폴더는 diagnostics/native-output-policy-20261024-*의 regression-a.log, selection-a-status.json, deployment.json이다. 현재 PC의 설치 지침/개인 프로필과 일반·개인 ZIP에 백업 후 반영하며 새 OpenCode/ACP 연결부터 적용한다. 클라이언트 설치 revision15에도 같은 규칙을 포함한다. 기존 프로젝트 AGENTS.md는 덮어쓰지 않는다.
