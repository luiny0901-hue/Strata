## 동작

### 도구 응답

도구를 제공한 요청의 일반 본문을 모델 응답이 끝날 때까지 보류한다. 해당 응답에 `tool_use`가 있으면 보류된 본문을 전달하지 않는다. 따라서 “저장했습니다”가 먼저 생성됐더라도 실제 도구 결과 전에 사용자에게 완료 본문으로 전달되지 않는다.

이 처리는 잘못된 완료 표현을 언어별로 추측하는 필터가 아니다. **도구 호출과 함께 나온 일반 설명 문장도 제외된다.** 대신 thinking·도구 이름·도구 인자·keep-alive는 계속 전달한다. 호출 ID·이름·입력·종료 이유·토큰 사용량은 보존하고 표시 블록의 인덱스만 연속되게 맞춘다. 후속 응답에 도구 호출이 없으면 저장 성공·실패를 포함한 최종 본문을 보존한다. 도구 실행과 승인 판단은 기존 클라이언트가 맡는다.

### JSON 응답

최신 일반 사용자 요청이나 시스템 지침의 마지막에 있는 명시적 긍정 지시를 좁게 인식한다. 예시는 `Return only JSON.`, `End with only JSON.`, `JSON만 출력해줘.`, `JSON으로만 응답해주세요.`다. 이전 사용자 요청을 최신 수정 요청보다 우선하지 않는다. 코드 울타리·인용·도구 결과·문서 문맥·부정문은 형식 지시로 사용하지 않는다.

해당 요청의 최종 답변에서 완전한 JSON 값 하나를 추출해 기존 검증기로 확인한 뒤 전달한다. 부연 설명과 코드 울타리를 제거하며 원래 JSON 안의 숫자·문자열 리터럴과 서식은 보존한다. 배열·문자열·숫자도 지원한다. 잘린 바깥 객체에서 안쪽 객체만 건지거나, 여러 JSON 중 첫 번째를 임의로 고르지 않는다. 중복 키·NaN·불완전·모호한 값은 성공 응답으로 내보내지 않고 오류로 처리한다. 검사기가 모델을 다시 호출하거나 답의 값을 고치지는 않는다.

이는 JSON 문법 전달 보완이며 JSON Schema 제약이나 답의 의미까지 보장하는 디코더는 아니다. Claude 공식 [Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)의 문법 제약 기능과 동일하다고 표시하지 않는다. 지원하지 않는 표현의 형식 요구나 도구 없이 발생한 모든 허위 성공 문장을 판별하는 기능도 아니다. 실제 산출물·요구사항 검증은 계속 필요하다.

## jsonschema 설치 후 추가 검증

사용자 요청으로 기존 Strata 가상환경에 문서의 범위 `jsonschema>=4.23,<5`를 설치했다. 설치 버전은 4.26.0이며 필요한 의존성 4개도 추가됐다. 기존 패키지 업그레이드는 없고 `pip check`는 충돌 없음이었다.

이전에 생략된 `test_invalid_generation_is_an_error_and_never_streams_content`와 `test_invalid_schema_is_400_and_local_refs_work`를 실제 실행했고, 관련 묶음은 **44개 모두 통과·생략 0개**였다. 이 두 검사는 CPU/HTTP 모의 엔진 검증이다.

현재 운영 서버의 기존 구조화 출력 API도 직접 확인했다. 잘못된 스키마는 생성 횟수를 늘리지 않고 400으로 거부했고, 정상 스키마의 `{"answer":4}`는 200으로 통과했다. 유효한 JSON이지만 스키마를 충족할 수 없는 출력은 `structured_output_failed` 502로 차단됐다. 두 생성 시험은 각각 정확히 한 번 실행됐으며 종료 후 서버는 유휴였다. 실행 중 서버가 새 라이브러리를 바로 읽어 재시작은 필요하지 않았다.

이는 JSON Schema를 명시한 기존 구조화 출력 요청의 검증이며 Claude의 모든 답변에 스키마를 자동 강제한 변경은 아니다. 설치 전 생략·기존 실패 기록은 그대로 보존했다. 새 기록은 `C:\Users\luiny\Strata-data\diagnostics\jsonschema-validation-20261027`의 `summary.json`, `cpu-suite.log`, `runtime-schema-probe.json`, `runtime-generations.json`, 패키지 변경·의존성 검사 로그에 있다.
