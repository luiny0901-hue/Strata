## 실패 이력과 한계

최초 Python 묶음은 기존 테스트의 `PYTHONPATH=tools`가 빠져1개 모듈을 불러오지 못했다. 경로를 지정한69개 검사를 별도 로그로 남겼다. 첫 코드 생성 시험은 시험 도구의 `source`가 전체 파일인지 함수인지 불명확해 모델이 전체 파일을 전달했고, 단일 함수 검사에서 거부됐다. 도구 매개변수 설명을 명확히 한 별도 시험에서2단계 수정을 확인했다. 준비 명령의 PowerShell 인용 오류도 있었으며 그 명령에서는 모델 요청이 실행되지 않았다. 알림 추가 후 최초 Node 검사는 압축 메시지 수의 옛 기대값에서 실패했다. 원본 메시지·동일 알림·요약1개가 보존되는 계약으로 검사를 갱신했고78개가 통과했다. 실패 원본을 성공으로 덮어쓰지 않는다.

언어 검사기의 문자·단어 검사는 보조 수단이며 원문/식별자와 불필요한 혼용의 구분은 저장 응답 검토를 함께 사용한다. 특정 모델의 모든 문장에서 외국어 혼용과 잘못된 추론을 완전히 차단했다고 보장하지 않는다. Rider 화면 조작·외부 PC/macOS 실기는 수행하지 않았다. 적용 후 OpenCode/ACP를 다시 연결하면 새 지침과 옵션을 읽으며 Strata 서버 재시작은 필요하지 않다.
