실제 Claude 요청에서 가져온 도구·시스템 형식으로 약 4.1만 토큰의 고정 입력을 만들었습니다. 요청 본문 파일은 전후 같은 SHA-256이며 `output_config.effort`만 순서대로 바꿨습니다. 도구는 실행하지 않았고, 진단용 출력 256·생각 예산 128을 양쪽에 똑같이 사용했습니다. 일반 코딩 설정의 예산은 바꾸지 않았습니다.

### 외부 환경의 무제한 재시도 설정을 가져오지 않음
