# Strata / OpenCode / Rider 연결 경로 점검

## 관측
- Strata localhost:8080 /health 응답 3회: 23.37, 22.12, 16.48ms. 상태 조회 응답이며 모델 추론 지연이 아니다.
- /status는 HTTP 오류로 조회하지 못했다. 해당 경로로 busy/idle 상태를 증명하지 않는다.
- 최근 OpenCode 세션에는 succeeded 기록이 있으나, 이번 검사는 실제 Rider 사용자 요청의 전체 완료시간을 재측정한 결과가 아니다.

## 승인 전달 경쟁 조건 보완
- 기존 응답 파일 직접 쓰기는 Node 읽기와 겹칠 때 불완전 JSON을 노출할 수 있었다.
- 완성된 임시 JSON을 atomic replace하여 전달하고 Windows 공유 잠금은 최대 0.5초 동안 제어 파일 교체만 재시도한다. 클릭이나 도구 실행은 재시도하지 않는다.
- 승인 요청 파일을 제거하기 전 in-flight ID가 해제되던 순서를 고쳤다. 승인 디스커버리 스레드가 같은 선택창을 다시 요청할 여지를 제거했다.
- 작업 UUID와 세션 모두를 확인한다. 취소 뒤 응답은 승인이 되지 않는다.
- 연결 종료 시 승인 스레드를 정리한 후 임시 디렉터리를 닫는다.

## 검증
- python -m unittest tools.test_acp_compact_display: 5개 통과. 부분 파일 미노출, Windows 잠금 재시도, 작업 종료·취소, 메시지 전달·최종 보고 보존 검사 포함.
- node --test tools/test_mcp_startup.mjs: 3개 통과.
- 실제 Rider 승인 선택 UI, 모델 추론, 262k 컨텍스트 및 장시간 작업 전체 검증은 이번에 실행하지 않았다. 전체 병목 제거 또는 일반적인 속도 향상을 주장하지 않는다.

## 적용
로컬 ACP wrapper 설치를 갱신한다. 새 OpenCode 연결부터 적용하며 실행 중인 작업을 강제 재시작하지 않는다.


## 짧은·긴 작업 경로 후속 검증
- Node 출력 복구 검사 22개, MCP 시작 검사 5개 통과. MCP 목록/도구 목록 자체가 응답하지 않는 상황도 새 회귀 검사로 포함했다. 25ms 테스트 제한에서 약 28ms/31ms에 종료했다. 이 수치는 합성 대기 제한 테스트이며 실제 Rider 작업시간이 아니다.
- ACP guard 6개 검사 그룹 통과: 무제한 대기 제한, 명시적인 긴 작업 제한 보존, 취소된 작업의 미실행, 필수 하위 작업 대기, 완료 뒤 추론 차단, 지침 중복 방지.
- Python 전송·작업 경계·파일 재확인 검사 8개 통과.
- 이번 추가 검사에서 새 런타임 결함은 재현되지 않았다. 실행 설정이나 모델 추론 강도를 추가로 변경하지 않았다.
- 실제 Rider 장시간 작업, 대규모 프로젝트, 262k 컨텍스트 부하 및 처리량 비교는 이번 후속 검사에 포함하지 않았다.
