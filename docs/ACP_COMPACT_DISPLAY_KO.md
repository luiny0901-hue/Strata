# Rider 생각 과정 표시 줄이기

선택적으로 ACP 전송 래퍼를 사용한다. 모델의 추론 설정과 내부 대화 기록은 바꾸지 않고, 실시간 및 기록 복원 시 전달되는 `agent_thought_chunk` 알림만 화면에서 숨긴다. 일반 답변과 완료 보고서, 도구 이벤트, 오류, 승인 요청, 완료 응답은 원본 그대로 전달한다. 도구 출력까지 요약하거나 제거하지 않는다.

설치된 Python으로 저장소의 `tools/configure_acp_compact_display.py`를 실행한다. 기존 `.jetbrains/acp.json`의 직접 OpenCode 실행 항목에 적용하고 기존 환경 설정은 보존한다. 원본 ACP 설정은 변경 전 백업한다. 반복 실행해도 래퍼를 중첩하지 않는다. 새 PC에서는 OpenCode 연결 설정을 마친 다음 실행한다. Python 실행 경로가 바뀌면 새 Python으로 다시 실행한다.

작업 중인 세션을 종료하지 않는다. 현재 작업이 끝난 뒤 Rider의 ACP 연결을 다시 시작해야 적용된다. 서버 BAT이나 High 추론 설정은 변경할 필요가 없다. 생각 과정이 숨겨진 구간에는 Rider의 기본 작업 중 표시를 사용한다. 별도 LLM 요약 요청은 발생하지 않으며, 모델 추론 시간이나 컨텍스트 사용량을 줄이는 기능은 아니다.

되돌리기는 해당 ACP 항목의 `command`를 래퍼 인자 `--` 다음 실행 경로로, `args`를 그 뒤 인자 목록으로 복원한다. 다른 설정이 이후 변경됐다면 전체 백업 파일로 덮어쓰지 않는다.

현재 실행기는 CUA 작업 단위 승인을 위한 ACP 요청 수명도 관리한다. 입력·승인 응답은 바꾸지 않고 전달하며 요청 완료·취소·연결 종료 때 승인을 해제한다. 실행기를 제거하면 CUA는 작업 수명을 알 수 없어 동작1회 승인으로 돌아간다. Windows 제어 파일의 일시적 잠금에는 짧은 재시도만 적용하며 실제 GUI 입력은 재전송하지 않는다. 상세 검사는 `TASK_APPROVAL_CACHE_20261023_KO.md`를 참고한다.

검증 범위: 구현 및 설치만 수행했다. Rider 실제 화면, 완료 보고서 표시, 취소 동작의 실행 검증은 수행하지 않았다.
