# Desktop 재시작 실동 검증 체크포인트 (2026-10-27, 최종)

범위: 현재 경로(Claude Desktop Code + OpenCodex + Strata)의 무인·재시작 시나리오 재검증. 사용자 위임으로 진행.

완료: OpenCode/Rider 잔재 정리·커밋(977b569b). 인계 3건(-a/-b/-c) 관찰 종료(부작용 없는 안전한 만료). 수정 저장: 만료 세션 유휴 처리·고정 error_code(418d6c26), 인계 대기 180초 상한 제거로 거래 기한까지 대기 후 조용한 첫 순간에 종료(e4b563d4), 로드 경계 문서화(d1e025fa), 4차 인계 관찰 기록 추가. 데스크톱 테스트 76개 통과. 운영 루트 배포 후 사용자 확인으로 supervisor 재시작(21:46:39)해 새 코드 로드. 4차 인계(-d)에서 Desktop 종료가 조용한 첫 순간에 실제 실행되는 것을 확인 — 요청 동작 실동 검증 완료.

최종 관찰: -d는 종료 직후(21:49:17) supervisor가 수동 재시작으로 교체되어 네이티브 재개·reopen 없이 `needs_attention`/`owner_interrupted`로 종료됐다(재개 미실행이라 부작용 없음). Desktop은 사용자가 직접 다시 열어 이 대화가 이어졌다. 거래 -d는 같은 세션에서 acknowledge로 수락한다.

남은 검증 1건: reopen 단계(supervisor가 Desktop을 다시 여는 것)는 이번에도 실행 기회가 없었다 — supervisor 교대·수동 재개로 계속 선행됐다. 재현하려면 Desktop·supervisor를 건드리지 않는 상태에서 인계를 한 번 더 제출해 관찰해야 하며, 제출 여부는 사용자 판단이다.

금지: 같은 작업의 중복 재시작 제출, 프로세스 강제 종료(정당한 절차 없이), 확인 없는 복구 계속, 푸시(미승인).
